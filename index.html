Services

What I can build for you

01

Websites

I work out what your site has to do, design it around that, build it, and get it live on your own domain. Made to load fast, work properly on a phone, and show up when someone searches your business name.

02

Web applications

Software that runs in the browser rather than a page you only read. Accounts and logins, records kept in one place, bookings, and reporting that turns all of it into something you can actually use. I plan it out with you, design it, build it, and get it live and running.

03

Mobile apps

Apps for phones, made for exactly what you need. I work out what it has to do, design it, build it, and get it ready to ship. Whatever you have in mind, ask about it and I will tell you honestly whether I can build it. I do not take on work I cannot deliver.

04

Hosting and domain

I get it online and keep it there. Hosting, your domain, and the security certificate so browsers show the padlock instead of warning your customers. Web applications run the same way. A mobile app goes out through the app store instead, and if it needs a server behind it, I set that up too.

05

I keep it running

Once it is live I can run it for you: changes when you want them, updates, and anything that goes wrong. If you would rather run it yourself, I hand it over. Every account is in your name from the start, so it is fully yours either way.

Websites

Website

v1.haydnmcintyre.ca

The previous version of this site, which I designed and built for myself before the current one. Plain HTML, CSS and JavaScript with no framework, page builder or template behind it. Responsive from a phone upward, with an animated particle field in the hero that reacts to the cursor, a scroll progress bar, section tracking that follows you down the page, and a lightbox on every screenshot. The contact form posts to a serverless endpoint that mails the message straight through, and falls back to opening the visitor's own mail app if that is ever unreachable. I set up the hosting, the domain and the certificate alongside it.

Web applications

ASP.NET Core · Project lead

Movement Unlimited

A full session tracking application for a pilates studio, replacing the paper and spreadsheet system they were running on. Members and staff sign in to their own accounts, sessions are booked and logged, client records are kept in one place, and the reporting side turns all of it into statistics on attendance and activity over time. What each person can see and do is controlled by their role.

  • Authentication, roles and permissions with ASP.NET Identity
